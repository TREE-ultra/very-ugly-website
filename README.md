中国废弃物循环利用股份有限公司 · 官方网站（第 1025 版）打包说明
============================================================

一、这是什么
------------
一个故意做得极度丑陋的静态企业网站（15 个页面），虚构公司“中国废弃物循环利用
股份有限公司”。三条铁律：全站零圆角、长方形顶死边框、配色令人生理不适。
纯前端静态站点：无后端、无框架、无外部 CDN、无图片文件，所有插图均为内联 SVG。
全部内容均为演示与恶搞，请勿用于真实生产环境。

二、怎么打开
------------
双击根目录的 index.html 即可（推荐 Chrome / Edge / Firefox 最新版）。
无需安装任何东西，也无需启动服务器；文件可以整个文件夹拷贝到任何地方打开。

四、好玩的功能
--------------
1. 首次打开约 1.6 秒后弹出 ¥1024 中奖弹窗，关掉 45 秒后它会回来。
2. 鼠标移动会掉星星；点右上角“还能更丑”或按键盘 U 键可开启全站极端模式
   （存在浏览器 localStorage 里，所有页面同步生效）。
3. 首页“重新配色（事故）”按钮会当场打乱全站配色。
4. 左右栏的搜索、客服、音乐、投票、二维码、访客计数都是假的，认真就输了。
5. 留言板留言保存在本机浏览器 localStorage（键名前缀 ugly_gb_），不会上传。
6. 全站导航、面包屑、页面总览、网站地图均可互相跳转，共 15 页。

五、兼容性说明
--------------
1. 需要启用 JavaScript：页头、导航、左右栏、页脚由 assets/shell.js 注入。
2. 全站为相对路径，直接把整个文件夹移到别处，或拷到 U 盘，仍可正常打开。
3. 窄屏（<1100px）会自动变成单栏，仍可正常使用；本站不保证“好看”。
